# Hindi-English AI Response Evaluation Benchmark

A hands-on benchmark for checking how well AI chatbots handle **Hindi, English and Hinglish**. Every response is scored by hand against a fixed rubric, labelled with its error types, and rewritten when it falls short. Python scripts then turn the annotations into comparison tables and charts.

The work mirrors what AI evaluators do on human-feedback projects: judge accuracy, instruction following, fluency, tone and cultural fit, and write a better answer when the model gets it wrong.

## What's in the benchmark

| | |
|---|---|
| Prompts | 120 (40 Hindi in Devanagari, 40 English, 40 Hinglish in Roman script) |
| Task types | translation, factual, instruction following, grammar, cultural, reasoning, writing, advice |
| Chatbots | 3 (named in the workbook's Settings sheet) |
| Responses | 360 (each prompt sent to each chatbot once) |
| Scoring | 1-5 on accuracy, instruction following, relevance, completeness, language quality, plus an overall score |
| Error labels | 15 types, e.g. `MISTRANSLATION`, `LITERAL_TRANSLATION`, `GRAMMAR`, `REGISTER_TONE`, `WRONG_LANGUAGE`, `REASONING_ERROR` |
| Corrections | every response with a real problem gets a corrected version and a written reason |

Full scoring rules: [guidelines/annotation_guidelines.md](guidelines/annotation_guidelines.md)

## Repository layout

```
data/
  prompts.csv                 120 prompts with notes on what to check
  annotation_workbook.xlsx    360-row scoring sheet with dropdowns
guidelines/
  annotation_guidelines.md    rubric, error labels, severity, rewrite rules
scripts/
  build_workbook.py           rebuilds the workbook from prompts.csv
  analyze.py                  validates annotations, writes tables, charts and summary
results/                      generated by analyze.py
```

## How the evaluation was run

1. **Collect responses.** Each prompt was sent to each chatbot in a fresh chat, and the answer was pasted into the workbook unchanged, with the date.
2. **Score.** Each response was scored on the five dimensions and given an overall score, following the guidelines.
3. **Label errors.** Up to two error labels per response, with a severity of minor, major or critical.
4. **Correct.** Responses with overall score 3 or below, a major or critical error, or a missed instruction were rewritten. The original answer is kept in its own column.
5. **Analyse.** `analyze.py` checks every row against the rules (missing reasons, rewrites without corrections, invalid scores) and produces the results.

## Running it

```bash
pip install -r requirements.txt

# optional: rebuild the empty workbook from prompts.csv
python scripts/build_workbook.py

# after filling in the workbook
python scripts/analyze.py
```

`analyze.py` writes:

- `results/summary.md`: headline numbers, findings, and all tables
- `results/examples.md`: five correction examples (original, error, fix, reason)
- `results/charts/`: overall score by chatbot and language, error-rate heatmap, most common error types
- `results/tables/`: every table as CSV
- `results/validation.txt`: rows that break the annotation rules

You can also export the Annotations sheet to CSV (for example from Google Sheets) and run `python scripts/analyze.py --input path/to/file.csv`.

## Notes and limits

- One annotator, one response per prompt per chatbot. Chatbot answers change over time, so results reflect the dates recorded in the workbook.
- Roman-script Hindi spelling varies (kyun / kyon); common variants are not counted as errors.
- The prompts focus on everyday Indian contexts and are not a full test of any model.
